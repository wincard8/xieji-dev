# 按《协纪辨方书》卷十核验报告

核验对象：本仓库 `engine.js`（宜忌引擎）。
比对底本：维基文库《钦定协纪辨方书》卷十「宜忌」（四库全书本）原文，共 22,882 字。
方法：不靠"看着像"，全部用脚本对原文做机械比对。

## 一、四段校验

| 段 | 做法 | 结果 |
|---|---|---|
| A 起例位次 | 卷十按语写明"某煞在某月值某日"（如「劫煞：寅申巳亥月值收日，辰戌丑未月值除日，子午卯酉月值执日」），逐月核对该煞落在建除第几位 | **138 项全过** |
| B 条目比对 | 按卷十的 sk-anchor 切出条目，分词后与引擎数组求差集 | 9/12 过，3 项为切分失败（该 3 条已在 D 段覆盖） |
| C 原文子串 | 引擎每条 `cite` 是否为卷十正文的连续子串 | 3/31 过——多数 cite 为节写，非逐字，故此法只能抓"编造"，抓不到"漏" |
| D 条目级 | 按"条目行"切分正文，逐条比对「宜」「忌」两个方向 | **26/43 过**，17 项失败经逐条查证均为条件从句/交叉引用造成的比对假阳性（见第三节） |

C 段失败的根因是：我把卷十原文节写成了 `cite`（如把「結婚姻」写作「结姻」），不是逐字抄。这本身不算错（页面展示用），但意味着 `cite` 不能当校验基准。D 段直接对正文分词，是更硬的证据。

## 三、D 段 17 项"失败"的逐条结论

全部为比对器切分问题，**不是引擎错误**：

1. **条件从句被截断**——「又為兵福宜安撫邊境」「又為天喜宜……」「與天恩併宜頒詔宣政事」「與月恩四相時德併宜修倉庫」等，卷十把"与某神同现才宜"的条件项写在主句后，脚本按「又为」「与…并」截断，导致主句外的项被判成"代码多出"。
2. **交叉引用**——「災煞：忌同刼煞」「月煞：忌同刼煞」，原文不复写清单，引擎复用同一数组，属正确实现。
3. **季节性条件**——执日/危日/收日的「霜降后立春前宜畋猎、雨水后立夏前宜取鱼」，引擎在运行时按节气窗口动态加入，不写进静态数组。
4. **土府并入**——月建与土府在卷十是两个条目，引擎合并为一条（便于展示），比对时需两段合并，已单独验证一致（44 项）。

## 四、明确没有验证到的部分

- **卷十「宜忌等第表」六等加减未复原**：吉凶相抵、凶又逢凶的精细裁决，本实现用"最重神煞定调 + 并集取忌"，因此凶日偏严（例如三煞值开日，卷十只忌五项，本实现按全表忌）。
- **未实现的神煞**：天愿、月恩、四相、时德、王日/官日/守日/相日/民日、不将、解神、除神、五合、六仪、五富、天仓、要安/敬安、玉宇/金堂、普护/福生/圣心、益后/续世、六黄道/六黑道（日层）、四击、四耗、四废、五虚、五墓、九坎、土符、地囊、归忌、血忌、往亡、复日/重日、五离、八专、无禄、反支、上朔、四离四绝、晦日、二至二分、土王用事、伏社、朔望、月忌日、人神所在、长短星。
- **时辰吉凶**：仅与外部独立实现（天机阁）对照 3 天 × 11 时 = 33 项，全合；未做全年对照。
- **历法**：48 项对照香港天文台 2026 年数据；干支以 1900-01-01 甲戌、2000-01-01 戊午为锚点验算。
- **词表合并的语义损耗**：如「結婚姻／納采／問名／嫁娶」并作「结姻／纳采／问名／嫁娶」，「營建宫室／修宫室」并作「营建／修宫室」，细粒度有损失，属展示层设计。

## 七、只实现了按语明文写出的裁决

卷十各条按语里，有两处把"遇德之后如何"写得极具体，这不是算术而是明文规则，据此实现（`engine.js` 中 `deSha` / `deJian`）：

1. **三煞／月刑 遇德**：「與天德月德天德合月德合併，止忌安撫邊境、選將、訓兵、出師、求醫療病，餘皆不忌」
   → 忌只保留这五项（另加百忌日），宜照常列出。
2. **月建 遇德**：「與天德月德天德合月德合天赦月恩四相併，止忌營建宫室…破土，餘皆不忌」
   → 忌只保留土府专忌那一串。

同时验证 **月破 遇德 仍"猶忌"**（不得减忌），与卷十「與天德月德…併猶忌之」一致。

`verify5.js` 抽样断言（2026 年）：

```
✓ 1-6(庚辰)  三煞遇德 → 忌仅五项（+百忌），宜 49 项
✓ 1-16(庚寅) 三煞遇德 → 忌仅五项（+百忌），宜 50 项
✓ 2-6(辛亥)  三煞遇德 → 忌仅五项（+百忌），宜 61 项
✓ 2-7(壬子)  三煞遇德 → 忌仅五项（+百忌），宜 53 项
✓ 2-21(丙寅) 建日遇德 → 忌仅土府专忌（18 项）
✓ 3-6(己卯)  建日遇德 → 忌仅土府专忌（17 项）
✓ 1-21(乙未) 月破遇德 → 忌仍 66 项（相符"猶忌之"）
```

这消掉了原先"三煞日有德也一律诸事不宜"的过度保守，但**没有**实现六等之间的相对加减。
