## 二、采纳并已修（历法，1 项）

**1929 年前时区**：原引擎一律用东八区。时宪历实际用北京地方平太阳时（约 UTC+7:45:40）。
改为按年切换后，三处临界朔日与史实/主流历表吻合：

```
1916-02-03 → 1916 年正月初一（史实；原引擎作 1916-02-04）
1914-11-17 → 1914 年十月初一（原引擎作 11-18）
1920-11-10 → 1920 年十月初一（原引擎作 11-11）
```

现代日期不受影响（2024-02-10、2026-02-17 仍为正月初一）。

## 三、驳回（2 项）

**① 土符忌缺「伐木」——原文无此条**

KR 卷十土符条：「土符地囊忌營建宮室修宫室繕城郭築隄防興造動土修倉庫修置産室開渠穿井安碓磑補垣修飾垣墻平治道塗破屋壞垣栽種破土」，至「破土」止，**无伐木**。
（伐木只见于月破、月厌、平日等条。）故不改。

**② 收日宜缺「栽種牧養」——原文作「不宜亦不忌」**

卷十原文：「不忌栽種牧養者……**故雖不宜而亦不忌也**」。
「不忌」不等于「宜」，若列为宜即与原文相悖。故不改。

## 四、据手工校订月表复核（4 条）

以用户手工核对的《协纪辨方书卷十月表.xlsx》为准（含「月表·六等」「各日类忌宜」「校勘说明」三页）。

**先验表本身**：把「月表·六等」66 格解析成 `{日类: {等第: [月支]}}`，与本引擎 `YUEBIAO` 逐格比对——

```
✅ 全部一致（66 格）
```

再核四条存疑，其中三条**报告是对的**，已补：

| 项 | 表内原文 | 处理 |
|---|---|---|
| 灾煞 | 「忌同劫煞；又为天火，**忌苫盖**」 | 补苫盖 |
| 大时 | 忌含**冠带**；「又为咸池，忌**取鱼**、乘船渡水」 | 补冠带、取鱼 |
| 月害 | 忌含「**置产室**」 | 补修置产室 |
| 天吏 | 忌含「**修置产室**」（比对时另发现） | 补修置产室 |

仍待者：建日忌「安葬」、开日忌「启攒」。二者属建除十二日，不在月表 11 个日类内，该表未覆盖，故不改。

## 十二、报告有误的一条（已更正我先前判断）

**P1-5「调候只做亥子丑取火、巳午未取水」——部分成立。**

我起初判它错，因为 `tiaohouOf()` 确实用《穷通宝鉴》118 格逐月条文。但复查发现 `baziWuxing()`
里另有一处**粗调候**：

```js
const tiaohou = [11,0,1].indexOf(bz.month.z) >= 0 ? 1
              : ([5,6,7].indexOf(bz.month.z) >= 0 ? 4 : -1);
if (tiaohou >= 0 && fav.indexOf(tiaohou) < 0) fav = fav.concat([tiaohou]);
```

它不看日主、不看原局，直接把火/水并入喜用——报告描述的正是它。已删除该段，
调候改由 `tiaohouOf()` 按原文逐格处理。
