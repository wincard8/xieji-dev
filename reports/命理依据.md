## 自查出来的一个硬缺口：藏干（已补）

渊海子平有《地支藏遁歌》：

> 子宫癸水在其中，丑癸辛金己土同；寅宫甲木兼丙戊，卯宫乙木独相逢。辰藏乙戊三分癸，
> 巳中庚金丙戊丛；午宫丁火并己土，未宫乙己丁共宗。申位庚金壬水戊，酉宫辛金独丰隆；
> 戌宫辛金及丁戊，亥藏壬甲是真踪。

**已按此表实现藏干**（12 支，主气／中气／余气，权重 0.6/0.25/0.15，月令 ×1.5），
旺衰改为「藏干加权 + 支持率」判定，并同时给出得令／得地／得势三项。

例：1990-06-12 午时 → 庚午 壬午 戊申 戊午
```
五行力量（含藏干）：木0 火2.45 土3.2 金1.6 水1.25（合计 8.5）
身强，支持率 66%，得令、得地3、得势1
喜 木水金　忌 火土
```

## 十二长生（已上线）

据《渊海子平·论天干生旺死绝》，阳干顺行、阴干逆行：

```
长生 沐浴 冠带 临官 帝旺 衰 病 死 墓 绝 胎 养
长生起点：甲亥 乙午 丙寅 丁酉 戊寅 己酉 庚巳 辛子 壬申 癸卯
```

用途：

1. **日主坐支**——如「日主戊，坐申（病）」，看自身根基。
2. **六亲所临** ——每位六亲标出它落在哪一柱、处于什么状态：

```
六亲：父·偏财（透干·胎）　母·正印（藏干·临官）　兄弟·比肩/劫财（藏干·病）
      妻·正财（无）　子·七杀（无）　女·正官（无）
```

这就能接上《论妻妾》「财衰败墓绝，主妻有疾不贤」这类判断——虽然「贤不贤」仍不下断语，
但「妻星是否衰绝」已经可见。

## 修正：自刑误判

原先「辰午酉亥」同属一组，凡两者相遇即算刑，导致「酉刑午」这类误判。
自刑只成立於同支（午见午、酉见酉），已改为仅同支才计。

影响：某命局（庚午 壬午 戊申 戊午）的大运分

```
乙酉  55 → 64   （酉不再刑午）
丁亥  31 → 40   （亥不再刑午）
```

## 病药（已上线，取原文可落地的部分）

《渊海子平·病药说》原文：

> 何以为之病？原八字中原有所害之神也；何以为之药？如八字原有所害之字，
> 而得一字以去之之谓也……「**有病方为贵，无伤不是奇；格中如去病，财禄两相随**。」
> 如用财见比肩为病，喜见官杀为药也；如用食神伤官，以印为病，喜财为药也。

据此把「破格原因」直接映射成病与药：

| 病 | 药 | 原文依据 |
|---|---|---|
| 比劫夺财 | 正官（官杀制比劫） | 「用财见比肩为病，喜见官杀为药」 |
| 财破印 | 比肩（比劫制财） | 财为病，比劫为药 |
| 枭神夺食 | 正财（财制枭印） | 「食伤以印为病，喜财为药」 |
| 伤官见官 | 正印（印制伤官） | 印制伤 |
| 财生煞无制 | 比肩（比劫制财） | 同上 |
| 官杀混杂 | 食神（食神制杀） | 食神制杀 |

界面显示「病药：病＝比肩，药＝正官（官杀制比劫·木）」，并标出药是否已在喜用：

- 药在喜用 → 「药在喜用，可解」
- 药不在喜用 → 「药不在喜用，需岁运补」

**未做的部分**：《病药说》还讲「病重药少／病轻药重」「去病得尽」与岁运去病，
这些要看全局轻重，不是查表能定的，故未实现。
