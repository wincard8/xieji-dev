装到 iPhone 主屏幕

装好后断网也能用，像本地 App 一样。

先说离线

首次打开会把整个应用（约 250 KB，单文件）缓存到手机里。之后断网、飞行模式、地铁里都能正常用， 所有推算都在本机完成，不上传任何数据。

只有第一次需要联网：下载并缓存。缓存好之后，即便卸载描述文件、断网，图标照样能用。

方式一 · 描述文件一步到位

点击下载一个「网页快捷方式」描述文件，安装后主屏幕自动出现图标。

下载安装描述文件
  1. 点上面的按钮 → 弹出「此网站正尝试下载一个配置描述文件」→ 点允许
  2. 打开 设置 → 顶部出现「已下载描述文件」（或 通用 → VPN与设备管理）
  3. 点进去 → 右上角安装 → 输入锁屏密码 → 再点安装
  4. 回到主屏幕，图标已出现
关于「未签名」：这个描述文件没有 Apple 开发者签名，安装页会显示「未签名」，属正常。 它内部只有一个网页快捷方式（网址 + 图标），不含任何权限、不读取任何数据，可随时删除。
删除方法：长按主屏幕图标删除；描述文件在 设置 → 通用 → VPN与设备管理 中移除。

方式二 · 添加到主屏幕无需描述文件

  1. 用 Safari 打开 协纪黄历（必须是 Safari，微信内不行）
  2. 点底部的分享按钮（方框带向上箭头）
  3. 往下滑，点「添加到主屏幕」 → 右上角添加
先打开协纪黄历
这种方式同样会生成图标并全屏运行，只是少了「安装」那几步确认。

说明

iOS 不允许像安卓那样直接安装安装包（.apk），所有网页应用都只能通过以上两种方式放到主屏幕。 两种方式得到的是同一个东西：一个图标，点开是全屏的黄历，不需要再输网址。

本页只是安装说明，不含任何脚本或统计。
